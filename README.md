# atlanticyacht---Block-12

# Atlantic Yachts

## Seiten

- Startseite: Willkommensbild und vier Yachtangebote
- Yachten: Bilder, Namen, Preise, Längen und kurze Beschreibungen
- Service: Beratung, Besichtigung und Hilfe beim Kauf
- Über uns: Vorstellung der Firma und Logo
- Kontakt: Öffnungszeiten und Formular mit Name, E-Mail und Nachricht

## Aufbau der Website

Oben auf jeder Seite stehen das Logo und der Firmenname. Mit dem Burger-Menü kann man die Navigation öffnen und zwischen den fünf Seiten wechseln.

Darunter kommt der Inhalt der jeweiligen Seite. Die Startseite zeigt zuerst ein grosses Yachtbild und danach die vier Angebote. Auf der Kontaktseite stehen die Öffnungszeiten und das Formular.

Auf dem Handy stehen die Yachtkarten untereinander. Ab 768 Pixeln stehen zwei Karten nebeneinander. Auch die Kontaktbereiche stehen auf kleinen Bildschirmen untereinander.

## HTML, CSS und Bootstrap

HTML enthält die Texte, Bilder, Links und das Formular. Die eigene CSS-Datei legt Farben, Schriftgrössen und Abstände fest.

Bootstrap hilft beim Layout. Es gestaltet die Karten, Formularfelder und das Burger-Menü. Mit Bootstrap passt sich die Aufteilung an die Bildschirmgrösse an.
Das Burger-Menü verwendet das JavaScript von Bootstrap.

## Ordnerstruktur

- html/: die fünf HTML-Seiten
- css/style.css: eigene Farben, Grössen und Abstände
- images/: Yachtbilder und Firmenlogo
- README.md: Beschreibung des Projekts
- Sitemap_Yachtverkauf_ZLI_Diogo.xlsx: Planung der Seiten in Excel
- Yacht_Webseite_Plan.drawio: Layoutplanung für Desktop und Handy

## Website öffnen

Die Datei html/index.html im Browser öffnen. Es muss nichts installiert werden.

## Kontaktformular

Name, E-Mail und Nachricht sind Pflichtfelder. Der Browser prüft die Eingaben. Das Formular verschickt keine Nachricht. Beim Absenden wird die Seite neu geladen.

## Bilder und Angebote

Die Yachtbilder stammen von Unsplash. Das Logo wurde für das Projekt bereitgestellt. Die Yachtangebote und Preise sind erfunden.
